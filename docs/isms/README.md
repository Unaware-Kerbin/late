# Late ISMS (ISO 27001:2022 style, mapped to SOC 2 TSC)

This folder is **documented information** for the Late open-source project as operated by its maintainers (ISO 27001 clause 7.5). It is **not** an ISO 27001 certificate and **not** a SOC 2 Type I or Type II report. A legal entity, operating period, and an independent auditor or certification body are still required for those.

The same control set is intended to serve both:

- **ISO 27001:2022** Annex A (selected controls in the Statement of Applicability)
- **SOC 2** Trust Services Criteria CC6–CC9, C1, A1, and P when cloud chat is enabled
